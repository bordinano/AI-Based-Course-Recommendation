\# AI-Based Course and School Recommendation System



A student-centered academic program and school recommendation

system for upcoming first-year university students in Muntinlupa City.



\## Technology Stack



\- Frontend: Next.js and React

\- Backend: Python and Flask

\- Database: PostgreSQL

\- ORM: SQLAlchemy

\- Containerization: Docker

\- Version Control: Git



\## Project Structure



\- frontend: Student-facing web application

\- backend: REST API and recommendation engine

\- docs: Technical documentation and research materials
